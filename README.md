## Project Overview

This project demonstrates how to build and evaluate a **Decision Tree Classification model** using Scikit-Learn and the built-in Iris dataset.

The notebook covers:

- Loading the Iris dataset
- Separating features and target labels
- Splitting data into training and testing sets
- Building a Decision Tree Classifier
- Using **Entropy** as the splitting criterion
- Controlling tree complexity with `max_depth=3`
- Visualizing the trained Decision Tree
- Making predictions on test data
- Evaluating the model using:
  - Accuracy
  - Confusion Matrix
  - Classification Report

## Dataset

The project uses the built-in **Iris dataset** available in Scikit-Learn.

The dataset contains measurements of iris flowers and three target classes:

- Setosa
- Versicolor
- Virginica

### Features

- Sepal length
- Sepal width
- Petal length
- Petal width

## Model Configuration

The Decision Tree is created with:

```python
DecisionTreeClassifier(
    max_depth=3,
    criterion="entropy",
    random_state=42
)
```

### Why these parameters?

- **`max_depth=3`** — Keeps the tree relatively simple and easier to visualize and understand.
- **`criterion="entropy"`** — Uses entropy/information gain to evaluate the quality of splits.
- **`random_state=42`** — Makes the result reproducible.

## Train/Test Split

The dataset is divided using:

- **70%** training data
- **30%** testing data
- `random_state=42` for reproducibility
- `stratify=y` to preserve class distribution

## Model Evaluation

The model is evaluated using three main metrics/tools:

### Accuracy

Measures the proportion of correctly classified samples.

### Confusion Matrix

Shows the number of correct and incorrect predictions for each class.

### Classification Report

Provides:

- Precision
- Recall
- F1-score
- Support

## Visualization

The visualization displays:
